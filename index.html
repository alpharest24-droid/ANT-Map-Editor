Dasar penggunaan

  • Geser kanvas untuk berpindah, cubit atau roda mouse untuk zoom, Pas Layar untuk melihat seluruh peta.
  • Koordinat peta: X ke kanan, Y ke bawah. Kereta arah NORMAL bergerak ke Y yang makin besar (ke bawah), REVERSE ke atas.
  • Putar 90° menampilkan peta seperti di game (NORMAL ke kanan). Hanya tampilan, data tidak berubah.
  • Grid (0.01) mengaktifkan snap 0,01. Tanpa grid, snap 0,005. Ujung track otomatis menempel ke ujung track lain yang dekat.
  • ID menampilkan/menyembunyikan nomor objek di kanvas.
  • Buat Baru mengosongkan peta (membuat map_id baru). Urungkan membatalkan perubahan terakhir.

Menambah objek

+ RelSeret dari titik awal ke titik akhir. Isi length (meter) dan speed (km/j). Type: MAIN, SWITCH, SPAWN (kereta muncul), END (keluar wilayah; centang bisa spawn agar juga jadi titik masuk). buffer: true = buffer stop di ujung buntu. dir NORMAL/REVERSE = track satu arah. teleportNormal/Reverse = lompat ke track lain.
+ SinyalKetuk di samping track. onTrack otomatis diisi track terdekat; periksa kembali.
+ WeselKetuk dekat titik percabangan, lalu isi normal (lurus) dan diverge (belok).
+ PeronIsi station (kode), name (nomor jalur), onTrack, dan topY/botY = ujung peron. Kereta berhenti 1 m sebelum ujung peron searah gerak.
+ BangunanGedung stasiun (hiasan), dengan nama dan rentang topY/botY.
+ JPLPerlintasan sebidang. tracks = daftar track yang dilintasi, y = posisi, no = nomor JPL.
+ StasiunKode & nama stasiun (dipakai sinyal masuk dan peron).

Ketuk objek untuk mengedit propertinya di tab Properti. Track terpilih bisa diubah dengan menyeret titik ujungnya. Salin/Tempel menggandakan objek dengan ID baru.

Sinyal & wesel

typeENTRY (masuk, wajib isi station), EXIT (keluar), SHUNT (langsir), BLOCK (blok otomatis), DISTANT (sinyal muka), REPEATER (pengulang).
facingArah kereta yang dilayani: NORMAL (ke bawah/kanan) atau REVERSE (ke atas/kiri). Panah di kanvas menunjukkan arahnya.
onTrackTrack tempat sinyal berdiri. Letakkan sinyal di bagian akhir track searah gerak; rute game berjalan dari sinyal ini sampai sinyal searah berikutnya.
protects(opsional, DISTANT/REPEATER) ID sinyal utama yang diulang. Kosong = dicari otomatis.
pairWesel berpasangan digerakkan bersama di game (garis kuning putus-putus di kanvas).
statePosisi awal wesel: NORMAL atau DIVERGE.

Jadwal KA

no / nNomor dan nama kereta.
t / mJenis (PASSENGER/FREIGHT) dan arah (NORMAL/REVERSE).
dari / tujuanKode stasiun asal dan tujuan (nama lengkap diambil dari Kamus Stasiun).
sTTrack masuk (track SPAWN atau track sinyal masuk).
tTPeron tujuan. Satu ID (222) atau beberapa pilihan (222,223); peron pertama = utama.
xTTrack keluar yang benar (dinilai di game).
sWJam muncul otomatis (0645). Kosong = kereta muncul saat pemain membuat rute dari sinyal masuk.
aT / dTJam tiba dan berangkat di peron.
sbStandby: kereta sudah berada di peron (atau track ber-buffer) saat dinas mulai.
tbBalik arah di peron (turnback).
finPerjalanan berakhir di peron (kereta hilang pada jam berangkat).
nc / ll / cl / cgJumlah kereta/gerbong, panjang loko, panjang kereta, jarak antar-kereta (meter).
rp / ri / rs / ruJadwal berulang: satu baris menjadi beberapa kereta. rp = jumlah kereta, ri = selang (menit), rs = selisih nomor KA (kosong = 2), ru = ulangi sampai jam (pengganti rp). Contoh KA 1501, sW 0600, rp 4, ri 4 → KA 1501 06:00, KA 1503 06:04, KA 1505 06:08, KA 1507 06:12. Semua jam (termasuk legs) ikut bergeser.
lkJenis lokomotif/rangkaian: CC201, CC203, CC204, CC206, CC300, CC205 (barang berat), BB303, BB304, D301 (langsir), KRL, KRD. Menentukan daya, berat dan rem.
hp / bkDaya (HP) dan rem layanan (m/s²), menimpa preset lk. Contoh rem: penumpang 0.9, barang 0.45–0.5.
horn(opsional) suara horn khusus, mis. cc206_lama → file horn_cc206_lama. Kosong = horn sesuai lk (horn_cc206, horn_krl, …).
lt / ct / tonBerat loko, berat per kereta/gerbong, atau berat total rangkaian (ton). Kosong = otomatis (penumpang 40 t, barang 60 t per gerbong).

Legs: perjalanan bersambung melewati beberapa stasiun. Tiap leg berisi tT, aT, dT (dan nc). Di game, leg ke-2 dst. bernomor KA 114 (2), dan seterusnya. Isi no / n di leg untuk mengganti nomor dan nama KA, mis. KA 245 Majapahit berangkat lagi sebagai KA 7021 Jayakarta.

Tab panel

PropertiData umum peta (nama, startTime, endTime, daftar stasiun) atau properti objek terpilih. Tambah field baru dengan + Field.
Jadwal KATabel jadwal dan tombol Legs.
Rakes StandbyRangkaian tanpa lokomotif yang diparkir (track, pos 0–1, arah, jumlah kereta).
Kamus StasiunKode → nama lengkap stasiun untuk papan jadwal dan pengumuman.
AuthorNama pembuat peta (watermark).
Kode JSONLihat/salin seluruh JSON, atau tempel JSON lalu Terapkan JSON.

Compile

Tekan Compile sebelum menyimpan. Editor memeriksa ID ganda, referensi track yang tidak ada, koordinat salah, wesel, sinyal, peron dan jadwal (termasuk tT). Start/End track dirapikan otomatis (Start = Y lebih kecil). Ketuk pesan untuk melompat ke objeknya. Semua perbaikan otomatis bisa diurungkan.

Simpan & buka

.antdLayout peta terenkripsi (tanpa jadwal), untuk dimainkan di game. Versi publik editor ini tidak bisa membuka .antd, jadi simpan selalu cadangan .json.
.antsJadwal terenkripsi, hanya untuk peta dengan map_id yang sama.
.jsonLayout + jadwal dalam teks biasa (bisa dibuka siapa saja).
Saat menyimpan .antd/.ants pilih dengan secret (hanya yang tahu secret bisa membuka) atau tanpa secret. Secret tidak bisa dipulihkan bila lupa, jadi simpan juga cadangan .json di tempat aman.

Buka layout dulu (Buka .json), lalu jadwalnya (Buka .ants). Jangan ubah map_id setelah jadwal dibuat.
